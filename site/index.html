Get started

One command, one click

You need Python 3.9+ and git. Nothing else to install.

Terminal
$ git clone https://github.com/radufarcas10/ghis.git
$ cd ghis
$ python3 ghis.py
  1. Your browser opensghis finds your repositories, the emails you commit with and your instance, all on its own.
  2. Pick where your code livesGitHub, GitLab, Codeberg, or any git host. A token adds pull requests and reviews, and is optional.
  3. Click Create my storyWatch it read your history live, then enjoy. A copy is saved so you can reopen it offline.

Command line

Scriptable, and the same story.

GITLAB_TOKEN=… python3 ghis.py collect \
  --provider gitlab --open

Install it

Get a ghis command with pipx.

pipx install git+https://github.com/radufarcas10/ghis
ghis

Host it for your team

A Docker image with an allowlist and expiring stories.

docker compose up --build

Privacy

Your code stays yours

ghis runs on your computer. It talks only to the host you choose, and only to read.

  • Tokens never touch disk. They stay in memory for one run and are never logged or shown.
  • No telemetry, no account, no server of ours. The page is a file on your computer.
  • Hosting it? Hosted mode adds an allowlist of hosts, HTTPS-only clones, no local file access and expiring stories.
  • Open, and tested. SECURITY.md spells out every guarantee, and the test suite checks the security-critical ones: the host allowlist, cross-site and DNS-rebinding blocks, and storage limits.

FAQ

Questions

Which commits count as mine?

Commits whose author email is one of yours. ghis finds them on its own: your account's emails, plus every address you committed with under your git name. You can add more.

Will the numbers match my GitHub profile?

Not exactly, and that is expected. ghis counts every branch of the repositories it can read, co-authored commits included, and counts rebased or cherry-picked copies once. Profiles count differently, often only the default branch and only the last year, and include work in repositories ghis never saw. Every story ends with a list of exactly what it covers.

Do I need a token?

No. Without one, ghis reads the repositories already on your computer. With a token it also includes pull or merge requests, reviews, repositories you never cloned and, on GitLab and Codeberg, your comments. If the gh or glab CLI is signed in, ghis uses that.

Does it work with my company's GitLab?

Yes. Self-managed GitLab, GitHub Enterprise Server, Forgejo and Gitea all work. ghis even reads your instance from the remotes of the repositories you have checked out.

Why don't my line counts include everything?

Lockfiles, build output, vendored code and snapshots are left out, so one npm install doesn't outweigh a year of work. Pass --count-all-files to include them.

Can I share my story?

Yes. Download the share card, an image of your highlights with no repository names, commit messages or emails on it. To share the whole story, use Share-safe data: it removes messages and renames repositories and teammates, keeping every number.
